# 📚 数学 · 个人知识库

> 一个基于 **Obsidian** 的个人笔记仓库，主要用于考研数学（数二）备考与地质学课程复习。

## ✨ 简介

本仓库是笔者的私人知识管理空间，沉淀日常学习中的：

- **考研数学（数学二）**：高等数学、线性代数的系统化笔记、题型总结、错题整理与学习记录；
- **地质学复习**：普通地质学（舒良树《普通地质学》第三版）的完整复习笔记、章节讲义与自测材料；
- **个人随笔**：日记、灵感碎片与短文。

所有笔记均以 Markdown 编写，通过 Obsidian 双向链接（`[[双链]]`）相互关联，构成可检索、可回溯的个人知识网络。
