# 沉积作用与大地构造

## 1. 长时段背景

大气圈和水圈的演化改变氧化还原条件、碳酸盐和蒸发岩形成条件；生物演化改变沉积物来源（叠层石、介壳、植物、煤、白垩）。现代主义需受地球演化非线性和不可逆性的约束，不能机械把现代环境套到所有古代。

沉积旋回可由全球海平面周期控制：一级与超级大陆形成/解体有关，二级与洋中脊扩张，三级与洋中脊变化和冰川，四级与冰盖、三角洲和局部过程有关。

## 2. 四个基本控制因素

1. **构造运动和沉降**：抬升提供物源和剥蚀区，沉降提供可容空间；决定盆地类型、物源方向、沉积速率和沉积物保存。
2. **全球/相对海平面变化**：控制海侵海退、岸线迁移、进积/加积/退积样式、河流类型和深水沉积。
3. **沉积物供给**：控制充填速度和水深；陆源供给强形成碎屑岩，供给弱且清洁可形成碳酸盐或蒸发岩；供给速度超过沉降/海平面上升有利海退。
4. **气候**：温度、降雨、蒸发和风控制风化、冰川、盐湖、珊瑚礁、煤、红层和纹泥；冰川消长还会改变全球海平面。

其他因素：内在沉积过程、生物活动、水化学、轨道/米兰科维奇周期、火山活动。

## 3. Wilson旋回与盆地

威尔逊旋回六阶段：萌芽、幼年、成年、收缩、残留洋、大陆碰撞。相应板块作用为裂谷/海底扩张、俯冲收缩、关闭碰撞和转换断层。

### 五类构造盆地及沉积

- **扩张带盆地**：大陆内裂谷以河流、湖泊红色粗碎屑和火山岩为主；陆间裂谷可有红层-熔岩-蒸发岩/浊积岩；被动陆缘形成陆棚碳酸盐/碎屑和陆隆浊积、等深流沉积。
- **俯冲带盆地**：海沟有深海沉积和浊积岩、混杂岩；弧前盆地火山碎屑、岩屑砂和浊积岩；弧内/弧间盆地火山碎屑、远洋软泥；弧后边缘海浊积岩和火山灰发育。
- **大陆碰撞盆地**：残留洋接受造山带碎屑、三角洲和海底扇；前陆盆地不对称，近造山带厚且变形强，磨拉石由海相/三角洲向河流、湖泊、山麓陆相过渡。
- **转换断层盆地**：局部挤压隆起和拉张沉降，邻近隆起、供源近，沉积快、相变和厚度变化大。
- **克拉通内盆地**：长期稳定，简单盆地浅宽、坳陷盆地厚、断陷盆地深；常有陆表海/陆棚碳酸盐、大型三角洲、红层和内陆湖泊组合。

## 4. 沉降-补偿关系

| 沉降/补偿 | 常见沉积 |
| --- | --- |
| 快速沉降、快速补偿 | 陆缘洪积-冲积 |
| 快速沉降、缓慢补偿 | 深水/较深水沉积 |
| 缓慢沉降、快速补偿 | 淤积-冲积、盆地充填 |
| 缓慢沉降、缓慢补偿 | 高成熟碎屑、浅海陆棚 |

## 5. 识别与自测

1. 解释构造、海平面、物源、气候如何共同决定海侵/海退序列。
2. 说明裂谷、被动陆缘、俯冲弧前/海沟、前陆和克拉通盆地的物源与沉积差异。
3. “厚度大”不能单独等于深水或快速沉降，必须结合补偿速度、粒度、相带和构造变形判断。
