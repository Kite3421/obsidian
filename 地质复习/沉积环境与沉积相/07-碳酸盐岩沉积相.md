# 碳酸盐岩沉积相

## 1. 碳酸盐岩工厂与基本规律

碳酸盐岩主要在温暖、清洁、透光、正常盐度、浅海（约南北纬30度之间）形成，生物骨骼、藻类、内碎屑、鲕粒、球粒和碳酸盐泥是主要来源。藻类光合作用消耗CO2并促使CaCO3过饱和，浅水碳酸盐生产率高；浑浊、深水、低温、高压和高CO2会抑制浅水碳酸盐工厂。

碳酸盐沉积区可概括为海岸/潮坪、浅水陆棚和深水盆地。粗粒颗粒搬运距离通常短；颗粒间灰泥多少、颗粒填集和胶结反映水动力。碳酸盐常大面积垂向加积，胶结、重结晶和白云化使原始相标志容易被改造。非海洋碳酸盐包括湖泊、土壤钙结核、洞穴、泉华和钙质沙丘。

## 2. 现代碳酸盐环境

- 无障壁滨岸：温暖、正常盐度、波浪和潮汐强，介壳海滩岩、珊瑚礁和碎屑滩。
- 有障壁潮坪：干旱、高蒸发、盐度高，潮上蒸发岩和叠层石，潟湖灰泥/球粒砂，水道鲕粒和滩砂，外缘礁滩。
- 台地和浅滩：潮汐、波浪控制颗粒滩和生物礁。
- 深水：远洋钙质/硅质软泥，浅水碳酸盐可由风暴流、浊流和滑塌搬入斜坡盆地。

### CCD

方解石沉积补偿深度（CCD）是CaCO3沉淀速率等于溶解速率的界面；其受温度、压力和CO2控制，通常约400-7000m。CCD以上碳酸盐可保存，以下逐渐溶解。深水碳酸盐可分非溶解、弱溶解、中等溶解、强溶解和完全溶解相；瘤状石灰岩、白垩和薄层灰泥灰岩-页岩互层是深水识别线索。

## 3. Irwin清水沉积三能量带

清水沉积指无或少陆源碎屑输入的陆表海碳酸盐沉积。

- **X带（远岸低能）**：浪基面以下，灰泥、水平层理、暗色缺氧，生物和有机质可堆积，常为烃源岩。
- **Y带（中部高能）**：波浪和潮汐活跃，浅水、透光、富氧；生物礁、生物碎屑灰岩、鲕粒灰岩、内碎屑灰岩，分选磨圆好、灰泥少、交错层理，优质储层。
- **Z带（近岸低能）**：浅而平，循环弱；泥晶灰岩、泥晶白云岩、白云岩和蒸发岩，干裂、鸟眼、叠层石，蒸发岩可作盖层。

## 4. Wilson九个标准相带

1. 盆地相：半深海-深海，还原，泥岩、页岩、浊积岩。
2. 开阔/广海陆棚相：外陆棚、风暴浪基面以下，生物扰动泥灰岩/石灰岩。
3. 台地斜坡脚相：浪基面以下、氧化界面以上，远洋和台地细碎屑。
4. 台地前缘斜坡相：浅水台地与深水过渡，灰砂和广海生物。
5. 台地边缘生物礁相：灰泥丘、生物碎屑丘、环礁/礁架。
6. 台地边缘浅滩相：高能颗粒滩、潮汐坝，分选好、洁净。
7. 开阔台地/陆棚潟湖相：正常盐度、浅水、颗粒质泥岩和生物丘。
8. 局限台地/半封闭台地相：循环受限、盐度异常、灰泥质颗粒岩、泥岩和白云岩。
9. 台地蒸发岩相：潮上盐沼、石膏和白云岩。

Tucker模式可简化为七类：潮上-潮间坪、潟湖/局限海湾、潮间-潮下浅滩、开阔陆棚/台地、礁和碳酸盐岩隆、礁前塌砾/泥丘、远洋碳酸盐泥/浊积盆地。

## 5. 台地类型与浅水层序

- **碳酸盐缓坡**：向广海平缓倾斜（<1度），无明显坡折，可为均匀缓坡或远端变陡缓坡。
- **镶边台地**：高能外缘礁滩/障壁与深水盆地之间有陡斜坡，向陆为低能潟湖；可为沉积型、过路型、侵蚀型。
- **孤立台地**：远离陆架、深水包围、陆源碎屑少；迎风侧礁、背风侧滩，边缘礁滩、内部潟湖，斜坡和盆地接收重力流及远洋沉积。

典型浅水碳酸盐海退/进积旋回向上变浅：高能颗粒滩/砾 -> 低能潮下开阔台地 -> 潮间带 -> 潮上带 -> 蒸发盐或非海相。潮上带有粉晶白云岩、干裂、鸟眼、岩溶空洞、钙质结壳、石膏盐岩；潮间带有叠层石、人字形交错层理、压扁和透镜层理；潮下带有泥晶、颗粒和礁灰岩、正常海相化石。

## 6. 生物礁

礁是具有抗浪骨架的碳酸盐建隆；广义礁包括生物和生物作用形成的厚层建隆，狭义生态礁强调造礁生物原地生长、迎浪建造和地貌凸起。形成条件：23-27℃左右、正常盐度约3%-4%、水深通常<30-50m、透光清洁、波浪供氧和养分、陆源碎屑少。

类型：裙/岸礁（与陆地相连）、堡/堤礁（离岸平行海岸）、环礁（远离海岸环形，中有潟湖）。发育阶段：定殖 -> 拓殖 -> 泛殖 -> 统殖。

礁复合体相带：礁骨架、礁顶、礁坪、礁后、泻湖、礁斜坡、塌积岩。礁前迎浪、角砾/塌积多；礁后背风、分选好；泻湖低能泥质；斜坡和塌积接收粗碎屑与远洋泥。礁核孔渗性好，可形成储层，但成岩胶结、白云化和溶蚀会改造储集性质。

## 7. 深水碳酸盐

深水环境在风暴浪基面以下，受正常垂向加积、重力流和潜流控制。重力流类型有岩崩、滑动/滑塌、碎屑流、颗粒流和浊流；可形成礁边缘/滩边缘的跌积或沉积边缘模式。识别深水碳酸盐要结合薄层灰泥灰岩-页岩、CCD溶解、重力流角砾/砂屑灰岩、滑塌变形和盆地位置。

## 8. 识别与自测

1. 比较硅质碎屑“水动力控制”与碳酸盐“生物生产 + 水动力 + 成岩改造”的差别。
2. 用Wilson九相带回答“从盆地到陆地”的相带迁移。
3. 如何区分礁与浅滩：礁是原地生长抗浪骨架，浅滩是异地搬运颗粒。
4. 解释“向上变浅”旋回及其与海平面/沉降/碳酸盐生产速率的关系。
