# 障壁岛、潟湖、潮坪、河口湾相

## 1. 障壁岛体系

障壁岛是波浪形成的长、低、狭窄砂岛，对海水有遮挡作用；体系由近岸平行障壁岛链、岛后潟湖/潮坪、连接潟湖和广海的潮汐水道（进潮口、退潮口、潮汐三角洲）组成。

有利条件：稳定砂源、平缓海岸平原、中小潮差（约2-4m）、中高波浪能量。成因可为海底沙洲上积并伴海平面下降、沿岸砂脊/砂嘴形成后与陆地分离，或沿岸砂脊沉没伴海平面上升。

水动力：波浪较强，潮汐小-中；潮流双向、脉动且涨落潮交替，潟湖和潮坪局部循环受限。障壁岛受海浪、风和风暴；潟湖/潮坪受潮汐；潮道受潮流侧向迁移。

## 2. 障壁岛亚相与垂向序列

- **临滨**：细砂粉砂，生物扰动；中上部中细砂和介壳，低角度楔状/槽状交错层理。
- **前滨**：冲洗淘洗强，分选好的砂砾岩，冲洗层理和双向交错层理。
- **后滨**：平行层理砂岩，极高潮或风暴才淹没。
- **沙丘**：细砂岩、风成中小型槽状交错层理和根迹。
- **漫冲积扇/冲溢扇**：风暴侵蚀障壁岛并把砂带入潟湖侧，薄层舌状或席状、前积/水平层理。

障壁岛砂体与海岸平行呈狭长带状，剖面底平顶凸。稳定海平面、连续供砂和适当沉降时形成下细上粗反韵律，向上层理规模增大，整体序列为临滨 -> 前滨 -> 后滨 -> 沙丘 -> 冲溢扇。

## 3. 潮道和潮汐三角洲

潮道是连接潟湖和海洋的潮下高能通道，类似曲流河侧向迁移。深潮道有大型双向面状交错层理砂砾岩，中浅潮道层理规模减小；底部冲刷面、介壳和砾石滞留常见，整体向上变细。进潮三角洲较易保存，退潮三角洲易受波浪改造；两者均有双向面状交错层理和向上变小的层理规模。

## 4. 潟湖

障壁岛遮挡的浅水半封闭盆地，经潮道与广海联系；波浪弱、面积小、盐度变化大，化石少、个体小、壳薄且以广盐性生物为主。

- **淡化潟湖**：淡水注入大于蒸发，细粒钙质粉砂岩和粉砂质泥岩，波状/水平层理，H2S和还原环境，沼泽化后可形成近海煤田。
- **咸化潟湖**：蒸发大于淡水注入，粉砂质泥岩、石膏、盐岩，水平和塑性变形层理，广盐性小壳生物；正常盐度珊瑚、棘皮等消失。

## 5. 潮坪

潮坪发育在低波浪、明显潮汐周期、平缓海岸，也可围绕潟湖、河口湾和潮控三角洲。按潮位分为潮上坪、潮间坪、潮下坪；按沉积物分清水碳酸盐潮坪和浑水碎屑潮坪。

### 碎屑潮坪特征

- 岩性：潮上多石膏盐岩/泥炭，潮间潮道砂与潮道间泥，潮下水下砂坝和生物碎屑。
- 构造：潮上水平纹层和泥裂；潮间脉状、波状、透镜状层理、潮汐束、再作用面；潮下平行层理、低角度和羽状/人字形交错层理。
- 生物：种类少但数量多，海陆混生，半咸水/广盐性生物多；生物潜穴、根迹、足迹、叠层石、蒸发岩和煤可见。
- 理想层序：潮下砂坪 -> 潮间混合坪 -> 潮上泥坪，整体向上变细，常为海退型正韵律。

## 6. 河口湾

海水入侵或海岸下沉使河谷沉溺，形成向海扩展的漏斗/喇叭状狭长海湾。通常潮差>4m，潮汐作用强于河流，涨潮壅水、退潮冲刷强，河流与潮流混合形成半咸水。

主要沉积单元：潮道、浅滩和潮坪。潮道充填通常为基底冲刷面 -> 介壳滞留 -> 大型双向交错层理浅滩砂岩 -> 平行/低角度层理砂岩；细粒沉积为砂泥薄互层，透镜、波状、脉状/压扁层理发育，海陆生物混生但无沼泽沉积。垂向总体向上变细：下部大型单向交错层 -> 中部大型双向交错层 -> 上部小型交错和泥披层理。

## 7. 识别与易混点

- 障壁岛：海岸平行狭长砂体、海滩冲洗层理、风成沙丘交错层理、潟湖泥岩组合。
- 潮坪：相反方向流水构造、人字形交错层理、再作用面、潮汐束、砂泥互层和暴露构造。
- 河口湾：强潮、漏斗形几何、半咸水生物、双向潮流构造，但无大面积三角洲平原沼泽。
- 透镜/波状层理不能单独指示潮坪，必须用潮汐束、双向性、潮道冲刷和相组合确认。
