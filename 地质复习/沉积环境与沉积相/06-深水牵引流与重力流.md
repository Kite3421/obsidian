# 深水牵引流与重力流

## 1. 等深流

等深流是由温盐环流和地球自转影响，沿海底等深线稳定流动的低速深部海流，常见于陆隆区，流速约5-20cm/s，沉积速率低。沉积物与深水原地泥质沉积伴生，多为不规则薄层或透镜，泥-砂级，中好分选，偶有砾石滞留；发育冲刷面、小型交错和水平层理，流向平行斜坡走向；生物扰动常破坏原始构造。流强周期变化形成细-粗-细序列，海平面上升期最易保存。

等深岩丘可呈长条/伸长状，长数十至数百公里、宽数十公里、高数百米至1公里以上，是深海大型等深流堆积体。

## 2. 内波和内潮汐

内波存在于不同密度水层界面或密度梯度内部；内潮汐是周期等于半日潮或日潮的内波，深水（通常>200-250m）更明显。沉积物波脊多平行斜坡走向，迁移方向与等深流不同，可排除普通等深流和滑塌。

识别：深水背景、双向交错层理、双向或单向递变层序、对偶层、泥岩-鲕粒灰岩-泥岩，泥砂级，生物扰动弱。与潮坪脉状/波状/透镜状层理的关键区别是水深和缺乏暴露构造。

## 3. 重力流形成条件

沉积物重力流是泥砂砾混杂、重力驱动、悬浮搬运的高密度流体。通常需：风暴浪基面以下的足够水深、坡角至少约3-5度、充足物源及地震/海啸/风暴/火山/洪水等触发机制。

## 4. 按支撑机理分类

| 类型 | 支撑机理 | 沉积特征 |
| --- | --- | --- |
| 岩崩/滑动/滑塌 | 块体破裂、沿剪切面运动 | 旋转块体、褶皱、断层、擦痕、沟模；滑塌内部塑性变形 |
| 碎屑流/泥石流 | 黏性、杂基黏附和浮力 | 杂基支撑、无分选、块状、随机组构，可反粒序 |
| 颗粒流 | 颗粒碰撞和分散压力 | 颗粒支撑、块状、长轴顺流，常见逆粒序或牵引毯 |
| 液化流 | 超孔隙压力、流体向上 | 泄水构造、砂岩脉、火焰构造、重荷模、包卷层理 |
| 浊流 | 湍流支撑，低-中密度 | 正粒序、底部侵蚀，经典鲍马序列 |

## 5. 鲍马序列

理想浊积岩自下而上：A底部递变层理段（高流态） -> B下部平行纹层（高流态） -> C流水波纹层/小型交错层理 -> D上部平行或细薄互层 -> E泥岩段 -> F深水页岩段。向上粒度变细、单层变薄、构造规模减小、流速降低。实际常不完整，原因是剖面位置、后期浊流侵蚀或沉积开始较晚。

## 6. 识别与自测

- 砾砂泥无分选无层理：先判碎屑流/冰碛物/扇根，再看基底擦痕和沉积位置。
- 逆粒序和颗粒支撑偏颗粒流；泄水构造偏液化流；正粒序+鲍马序列偏浊流。
- “双向交错层理”必须先判断是潮坪/河口湾的浅水潮汐，还是内波内潮汐的深水沉积。
- 深水重力流砂体常形成海底扇、沟道和天然堤，具有储层意义；泥质远端可成为盖层或烃源岩。
