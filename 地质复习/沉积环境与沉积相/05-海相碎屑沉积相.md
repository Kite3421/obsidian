# 海相碎屑沉积相

## 1. 海洋分区与一般特征

海洋约占地球表面积70.8%。海底地形包括陆棚（平均坡度约0.1度、水深一般<200m）、大陆坡（约4-7度、水深至1500-2500m以上）、陆隆和大洋盆地（常>2000m）。海水平均盐度约3.5%，弱碱性，水动力有波浪、潮汐和海流；海流可搬运细粒物质，深水还可有等深流、内波内潮汐和浊流。

海相沉积岩性丰富、厚度大、分布广、成熟度高，层理/波痕/生物遗迹丰富，常见海绿石、鲕绿泥石、自生磷灰石和锰结核。按海底地形分滨海、浅海、半深海、深海。

## 2. 无障壁滨岸相

波浪控制为主，潮汐和沿岸流共同改造。滨岸带由海岸沙丘、后滨、前滨、近滨组成；高能海岸以砂质为主，低能海岸为粉砂泥质并有宽潮间带。

- **海岸沙丘**：海岸砂经风改造，细中砂、成熟度高、重矿物富集，大型槽状交错层理，前积纹层倾角约30-40度。
- **后滨**：仅特大高潮/风暴淹没，较粗砂、平行和小型交错层理。
- **前滨**：冲浪冲洗强，中砂，低角度冲洗交错层理、对称/不对称/菱形波痕、贝壳碎屑。
- **近滨/临滨**：低潮线至波基面，沿岸水下砂坝和凹槽；上部粗、下部细，槽状/板状/双向交错层理向下减小，生物扰动增加。

砂质高能海岸常形成下细上粗反旋回进积序列：滨外 -> 近滨 -> 前滨 -> 后滨。砂体平行海岸呈线状、成排出现，剖面底平顶凸或席状。

## 3. 浅海陆棚

位于正常浪基面与陆棚边缘之间，水深约10-200m，可为陆表海或陆缘海。水动力包括潮流、风暴流和海流：

- **潮控陆棚**：往返/回转潮流形成沙垄、潮汐沙脊和沙波，砂体平行或横向于潮流，发育再作用面和交错层理。
- **风暴控陆棚**：风暴浪冲刷近岸，回流以密度流向海搬运，形成风暴沉积和风暴岩（tempestite）。理想序列：底部侵蚀面/滞留或粒序层 -> 平行层理砂岩 -> 丘状交错层理砂岩（HCS） -> 顶部泥岩。单层向上变细，HCS波长大、波高小、低角度上拱。
- **海流控陆棚**：洋流搬运和改造残积物，形成砂波、砂脊和砾石滞留层。

## 4. 半深海与深海

- **半深海**：水动力弱，泥质、浮游生物和火山碎屑为主；无植物，腹足类、双壳、腕足、放射虫、有孔虫可见。原地沉积为蓝色/红黄/绿色软泥、碳酸盐软泥、火山泥和冰川海洋沉积；异地沉积包括重力流、等深流、内波内潮汐。
- **等深流沉积**：沿等深线平行流动，薄层、透镜状、泥至砂级、中好分选、冲刷/交错/水平层理、流向平行斜坡走向，强度周期变化形成细-粗-细序列。
- **深海**：大洋盆地、水深通常>2000m，底层水冷、底栖生物少；沉积物有红色黏土、抱球虫/翼足/放射虫/硅藻软泥、锰结核和浊流沉积。红色黏土形成于低沉积速率、低生产力、相对氧化且低于CCD的远洋环境。

## 5. 滨浅海识别

高成熟度石英砂岩、波浪型粒度概率曲线、冲洗层理和波痕、海相生物化石、平行海岸的线状砂体及下细上粗进积序列是关键组合。深水泥岩需要与湖泊深湖和潟湖泥岩用化石、海绿石、盐度和盆地位置综合区分。

## 6. 识别与自测

1. 写出海岸沙丘-后滨-前滨-近滨的水动力和沉积差异。
2. 解释风暴岩四段式序列和丘状交错层理成因。
3. 比较潮控、风暴控、海流控陆棚的底形和层理。
4. 看到HCS要考虑风暴岩，但必须查侵蚀底面、粒序层和上覆泥岩，不能只凭交错层理。
