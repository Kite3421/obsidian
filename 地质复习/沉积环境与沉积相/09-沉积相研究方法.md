# 沉积相研究方法

## 1. 岩性与产状

- 颜色反映古气候和Eh：灰黑色偏还原，红棕黄偏氧化，绿色为弱氧化-弱还原。
- 岩石类型、石英/长石/岩屑和轻重矿物组合可恢复母岩、物源方向、搬运距离和构造背景。
- 自生矿物：海绿石和鲕绿泥石是海相标志但形成深度/温度不同；海绿石偏较深、弱氧化-弱还原，鲕绿泥石偏温暖浅海；高岭石偏酸性大陆，伊利石/蒙脱石偏中性-碱性。
- 特殊岩石：叠层石碳酸盐常指潮坪，鲕粒灰岩指高能滨海/台地，蒸发盐指干旱闭塞，礁灰岩指浅海抗浪生物建隆，磷块岩多指浅海海洋，锰结核常见深海。
- 结构指标：粒度、分选、磨圆、成熟度、支撑方式、杂基含量、粒度概率曲线和C-M图。
- 产状指标：地层厚度、砂体形态、接触关系、剖面结构和层序。剖面向上变细可见河流、潮坪、河口湾、浊积岩、风暴岩；向上变粗可见三角洲、湖泊、无障壁海岸、海滩。

## 2. 生物标志

观察化石种属、生态、盐度耐受、底栖/浮游/游泳生活方式、壳体大小厚薄、植物根迹、遗迹化石和生物扰动。淡水腹足/双壳/介形虫偏湖泊；海相生物、海绿石和海相遗迹偏海洋；半咸水和广盐性小壳生物偏潟湖/河口湾；植物根、泥炭和煤偏陆上湿地或三角洲平原。

## 3. 地球化学标志

- 元素含量受母岩、古气候、水体性质、生物、成岩和后生作用共同控制。
- 盐度：B法、B/Ga、Sr/Ba、C/S、Sr/Ca、Rb/K、V/Ni、Mg/Ca和磷酸盐法等；Sr/Ba在湖泊常<1但只能作辅助证据。
- 氧化还原：Fe-Mn矿物组合、黄铁矿/菱铁矿及Fe价态反映Eh-pH。
- 温度和气候：碳酸盐-海水O同位素分馏；C、S、H同位素辅助古气候、盐度、硫循环。

## 4. 测井与地震

- 自然电位曲线最常用，电阻率辅助；倾角测井、成像和声波全波可识别层理和沉积倾向。
- 箱形常指厚层均质砂体（辫状河/河道）；钟形多指向上变细河道充填；漏斗形/反钟形多指向上变粗的河口坝、三角洲前缘或海滩。
- 地震相使用振幅、连续性、频率、几何和内部反射：冲积扇楔状/杂乱丘状下超，河流平行-断续，三角洲S型/斜交/叠瓦前积，深水扇和浊积沟道低连续性或多期叠置。

## 5. 古地理与古水流

古地理分析包括侵蚀区位置和母岩、古地形、沉积区边界、搬运介质、水动力、水化学和资源分布。古水流测量依赖板状/槽状交错层理、波痕、槽模、底面冲刷构造、碎屑和化石优选方位；应做古流向校正、矢量平均和构造倾斜校正。

## 6. 相剖面与编图

工作流程：全面收集剖面、岩心、测井、地震、构造、古生物和已有古地理资料 -> 统一年代地层划分与对比方案 -> 踏勘 -> 控制/辅助/路线剖面测制 -> 逐层描述和目的性采样 -> 室内薄片、粒度、重矿物、同位素和化学分析 -> 建立相组合/相模式 -> 编制基础图件和综合岩相古地理图。

注意三类问题：**定时**（选择等时界面）、**穿时**（岩石地层单位可能跨时代）、**相变**（同期异相与同相异期）。不能简单“砂对砂、泥对泥”对比。

主要图件：柱状剖面、岩相剖面/对比剖面、等厚图、粒度和C-M图、砂岩厚度/层数图、砂泥比图、泥岩颜色图、重矿物图、化石图、Fe/S/有机碳/Sr-Ba等值线图、测井划相图、砂体几何图、岩相古地理图和勘探预测图。

## 7. 识别纪律

1. 单一标志不定相；必须组合证据。
2. 先描述后解释：先写“砂岩、粒度、层理、化石”，再写“可能为河流/潮坪”。
3. 先判断事件层，再判断背景相；风暴、浊流、洪水可叠加到多个环境。
4. 用相律和相模式做可检验预测，并用横向剖面、测井和地震验证。

## 8. 自测

- 给出一个“海绿石 + 高成熟石英砂岩 + 交错层理”的多证据定相流程。
- 为什么粒度分析存在多解性？如何与沉积构造和层序结合？
- 设计一个野外剖面采样计划，说明样品的目的性和代表性。
