# 沉积环境与沉积相 - 基本概念

## 1. 学科关系

- **沉积岩石学**：研究沉积岩的物质成分、结构、构造、分类、形成作用及分布。
- **沉积学**：研究沉积物和沉积岩的成分与成因；时间不是首要维度。
- **沉积相**：沉积环境及其形成的沉积岩（物）特征的综合，即“环境 + 岩石/沉积物特征”。
- **沉积体系**：具有成因联系的多个沉积相的三维集合，范围大于单个沉积相。
- **岩相古地理**：以沉积相为核心重建古环境、古地理和沉积物空间分布。

## 2. 沉积环境的五类要素

1. 自然地理：海、陆、河、湖、沼泽、沙漠、冰川及地势。
2. 气候：干湿、冷热、降水、蒸发、风。
3. 构造：盆地隆坳、沉降速率、断裂、板块背景。
4. 介质物理性质：水/风/冰的类型、流动方式、能量、温度、密度。
5. 介质化学性质：盐度、pH、Eh、溶解度、氧化还原和生物化学平衡。

## 3. 相标志四大类

### 岩性标志

- 颜色：灰黑色多指还原-强还原；红棕黄多指氧化-强氧化；绿色多指弱氧化-弱还原。
- 岩石类型和矿物：石英、长石、岩屑及轻重矿物组合可示物源；海绿石、鲕绿泥石、磷灰石、锰结核、蒸发岩等可示环境。
- 结构：粒度、分选、磨圆、成熟度、颗粒/杂基支撑、粒度概率曲线和C-M图。
- 沉积构造：层理、波痕、冲刷-充填、泥裂、雨痕、叠瓦、鸟眼、潮汐束等。

### 古生物标志

- 生物种属、生态位、盐度耐受范围、底栖/游泳/浮游生活方式。
- 化石组合、壳体大小和厚薄、植物根迹、遗迹化石及生物扰动。

### 地球化学标志

- 元素和比值：B/Ga、Sr/Ba、C/S、Sr/Ca、Rb/K、V/Ni、Mg/Ca等可辅助判断盐度、物源、离岸距离和氧化还原。
- 稳定同位素：O同位素古温度；C、S、H同位素辅助古气候、盐度、氧化还原和硫循环。
- 同生矿物组合：铁锰矿物组合、黄铁矿、菱铁矿和海绿石反映Eh、pH及水深。

### 地球物理标志

- **测井相**：自然电位曲线最常用，电阻率辅助；曲线形态反映粒度旋回和砂体类型。
- **地震相**：反射振幅、连续性、频率、几何形态和内部结构；冲积扇常楔状/杂乱，三角洲常前积，河流常平行-断续。

## 4. 相组合、相序与相分析

- **相组合**：具有成因或环境联系、共同产出的相的集合。
- **相序**：一系列相及其过渡关系，反映空间相带的有序变化。
- **相分析**：根据相标志、相组合和相序恢复古环境；核心方法是“将今论古”与岩石类比。

### 沃尔特相律

只有在横向上彼此邻接、沉积连续且无间断的相区，才能在垂向上相互叠置。用途：由垂向序列推断横向相带，或由横向资料预测垂向层序。遇到侵蚀面、间断或快速事件沉积时必须谨慎。

## 5. 相模式

相模式是以相序规律、现代沉积和古代研究为依据，归纳出的具有普遍意义的沉积相空间组合关系。功能：

1. 作为对比标准；
2. 作为研究提纲和指南；
3. 预测新区相带；
4. 为水动力解释提供基础。

形式可为直观、实际地区性、物理模拟和数学模拟模式。

## 6. 综合分类

常用层级：**相组 -> 相 -> 亚相 -> 微相**。

- 陆相组：残积、坡积-坠积、山麓-洪积（冲积扇）、河流、湖泊、沼泽、沙漠、冰川。
- 过渡相组：三角洲、潟湖、障壁岛、潮坪、河口湾。
- 海相组：海岸、浅海陆棚、半深海、深海。

大陆沉积一般碎屑岩/黏土岩占主导，棱角多、分选差、层理多样、氧化色明显，化石以淡水和陆生组合为主。海洋沉积范围广、成熟度高，潮汐、波浪和海流发育，常有海相化石、遗迹化石和海绿石等自生矿物。

## 7. 识别与自测

### 如何识别“相”而不是只认一个标志

1. 先判断地理位置和水深，再判断主要营力。
2. 至少选择一项岩性、一项构造、一项生物/化学/几何证据交叉验证。
3. 检查剖面层序是否合理，是否存在侵蚀面、事件层或穿时问题。
4. 用相模式提出可检验预测，再用邻井、横剖面、测井和地震资料验证。
