# 陆相沉积相

## A. 冲积扇相

### 环境与过程

冲积扇是山地河流携带粗粒碎屑在山口坡度突然变缓处形成的扇形/锥形堆积体，是陆相中最粗、最差分选、近源的沉积单元。强烈构造抬升、物理风化、干旱或半干旱气候、山口坡折和洪流有利于形成大型冲积扇。平面上河道从扇顶放射状分流；纵剖面下凹透镜状或楔状，横剖面上凸。

### 沉积类型

| 类型 | 支撑/搬运 | 岩性与构造 | 位置 |
| --- | --- | --- | --- |
| 泥石流 | 黏性重力流，泥质杂基支撑 | 砾砂泥混杂、极差分选、块状、无定向无层理 | 扇上部、扇根常见 |
| 河道充填 | 暂时性牵引流，推移/跃移为主 | 砾石和粗砂，冲刷-充填、交错层理、可见叠瓦 | 扇根和扇中 |
| 漫流/片流 | 洪水漫出河道，快速减速 | 砂砾席状体，块状、平行或交错层理 | 扇中至扇缘，主体沉积 |
| 筛状沉积 | 水下渗，细粒缺少 | 棱角砾石、颗粒支撑、填隙物少、成层差 | 扇面局部，少见但有特色 |

### 亚相与层序

- **扇根/近端扇**：坡度最大，直而深的主河道；泥石流 + 河床充填；混杂砾岩、杂基支撑、叠瓦砾岩，化石少。
- **扇中**：辫状分支河道和漫流沉积；砂/砾比增大，砾状砂岩、交错层理、冲刷-充填，河道间泥岩可有干裂雨痕。
- **扇缘/远端扇**：地形平缓，漫流为主；砂岩、粉砂岩、黏土岩，分选变好，局部膏盐，暴露构造多。

干旱型扇泥石流、筛状和片流比例高；湿润型河流作用强，扇根至扇缘分异明显。垂向可形成扇进（向上变粗）或扇退（向上变细）序列。

### 识别冲积扇

- 粗砾岩为主，棱角状、低成熟度、分选差，红/棕红/黄色常见；化石和有机质少。
- 厚层席状或透镜状砂砾岩，盆地边缘呈楔状；地震常杂乱反射、丘状下超，向扇端连续性和振幅改善。
- 泥石流的杂基支撑、无层理与河道沉积的颗粒支撑、叠瓦和交错层理共生。
- 与山麓坡积、河流、湖/海、扇三角洲或风成砂相邻是重要组合证据。

## B. 河流相

### 流水过程

- 河流以紊流为主；层流质点平行、规则，紊流有惯性切应力和漩涡举扬。
- 弯曲河道发育横向环流：表流向凹岸、底流向凸岸，产生凹岸侵蚀、凸岸边滩侧向加积。
- 搬运：悬移（细粒）、跃移（砂）、推移/滚动（粗粒）。
- 洪水溢出河床，悬移质垂向加积形成天然堤、决口扇和泛滥平原。

### Rust四类河流

以分岔参数（每个平均蛇曲波长内砂坝数，临界1）和弯度指数（河道长/河谷长，临界1.5）划分：

| | 单河道 | 多河道 |
| --- | --- | --- |
| 低弯度 | 顺直河 | 辫状河 |
| 高弯度 | 曲流河 | 网状河 |

### 曲流河亚相

1. **河床**：砂岩为主，底部滞留砾石，底冲刷面明显；边滩（点砂坝）侧向加积，槽状/板状交错层理，向上变细。
2. **堤岸**：天然堤为细砂-粉砂-泥薄互层，波状/上攀层理、干裂、根迹；决口扇较天然堤粗，透镜/舌状，向上可变细或变粗。
3. **河漫**：河漫滩粉砂和黏土，水平/波状层理及暴露构造；河漫湖泊黏土、水平层理、淡水化石；河漫沼泽富泥炭和植物。
4. **牛轭湖**：截弯取直后废弃河道，粉砂-黏土，水平/交错层理，淡水软体动物和植物残骸，透镜状。

曲流河垂向模式是典型“二元结构”：下部底层沉积（滞留 + 边滩，侧向加积）之上为顶层沉积（堤岸 + 河漫，垂向加积）；二元结构可多阶重复。

### 辫状河

多河道、宽浅、坡降大、宽深比通常>40、弯度小、河道迁移快、心滩发育，底负载占主导。心滩可为纵向、横向、斜向砂坝或江心洲；砂砾岩、巨型/大型槽状和板状交错层理、冲刷面、叠瓦构造发育，向上变细不明显。泛滥平原、天然堤、决口扇和牛轭湖不发育，垂向表现为“砂包泥”。

### 网状河

低坡降、窄而深的多河道网状系统，河道间为稳定冲积岛、湿地和泛滥平原，占面积60%-90%，泥炭丰富；悬浮负载和垂向加积为主。河道砂体窄厚、墙式或鞋带状；整体为“泥包砂”。植被和黏结性强有利于河道稳定。

### 识别古代河流

- 砂岩、粉砂岩、黏土岩为主，成熟度低；底部侵蚀-冲刷面和泥砾常见。
- 板状/槽状交错层理、平行层理和正韵律；平面砂体呈弯曲长条、带状、树枝状，剖面透镜或板状。
- 曲流河看“二元结构 + 点砂坝 + 天然堤”；辫状河看“多冲刷面 + 心滩 + 粗砂砾 + 砂包泥”；网状河看“窄厚河道 + 厚泥炭湿地 + 泥包砂”。
- 测井常见箱形、钟形、尖峰形；油气储层多为下部边滩或心滩砂体。

## C. 沙漠相

### 环境与沉积单元

干旱、少雨、高蒸发、植被稀少，风作用强，常分为岩漠、砾漠、风成砂、黄土、间歇性河流/旱谷、干盐湖或内陆萨布哈。风搬运能力约为流水1/300，不能搬运溶解物，颗粒常以弹道式跃移。

- **岩漠**：吹扬和风蚀使基岩裸露，地质记录保存少，雅丹是风蚀地貌。
- **砾漠/Gobi**：细粒被吹走后残留粗砾，表面撞击痕、磨光面和风棱石，保存少。
- **风成砂**：中细砂，石英富集，分选和磨圆好，成熟度高，毛玻璃状霜面，大型单向交错层理。
- **黄土**：悬浮搬运的粉尘，砂、黏土和少量方解石，浅黄，孔隙大，常无层理。
- **旱谷/间歇河流**：暴洪、河道不固定、辫状，粗粒扇状堆积，风成和水成沉积交互。
- **干盐湖/萨布哈**：粉砂泥互层，夹石盐、石膏和薄砂层，蒸发岩发育。

沙丘亚环境包括沙丘、沙丘间和砂席；沙丘类型有新月形、横向、纵向和锥形/沙山。

### 识别古代风成砂岩

巨大厚层的高角度单向交错层理（前积纹层约25-34度，层系可数十米）、极好分选和磨圆、石英霜面、黏土含量低、缺云母、缺海相化石和煤；可与蒸发岩、间歇河流共生。注意：仅有大型交错层理仍需结合风成波痕、砂体连续性和缺少海相证据。

## D. 冰川相

### 冰川过程

冰川是雪在雪线以上积累、压实、重结晶后形成的缓慢流动冰体，类型有山谷冰川、山麓冰川、冰盖/冰帽。侵蚀包括刨蚀（冻结-拔掘）和磨蚀（含岩块冰体研磨，形成擦痕、沟槽、磨光面、羊背石）。

冰川碎屑以“悬浮”方式随冰体运输：侧碛、内碛、底碛、终碛和中碛。**冰碛物/till**直接由冰川堆积，**冰碛岩/tillite**是其石化产物。

### 冰水沉积

融冰水再搬运产生层状、具分选的沉积：蛇丘、冰碛阜、鼓丘、冰水平原、冰湖纹泥和冰海沉积。纹泥是浅色粗粒春夏层与暗色细粒秋冬层的季节韵律，冰海常有坠落石（浮冰筏运粗块刺穿或压弯纹层）。

### 冰川岩相与识别

- **块状冰碛岩**：无层理、极差分选、双/多众数、杂基支撑、粒度跨度大；砾石有擦痕和磨光面；下伏基岩有沟槽、擦痕、磨光面。
- **带状冰碛岩**：颜色/成分/粒度条带，反映冰下混合和剪切。
- **层状砾岩砂岩**：冰融水成因，具冲刷、水平和交错层理，分选较好。
- **纹层岩**：砂粉黏土纹层交替；有坠落石支持冰海/冰湖，但缺少坠落石不能排除冰川成因。

### 陆相沉积相的综合识别自测

1. “杂基支撑、无分选、无层理”优先考虑泥石流或冰碛物；用擦痕、下伏基底和块体来源区分。
2. “粗砾 + 席状 + 红色 + 盆地边缘”偏冲积扇；“多冲刷面 + 交错层理 + 心滩”偏辫状河。
3. “巨大单向交错层理 + 高分选石英砂 + 缺海相化石”偏风成砂。
4. “纹泥 + 坠落石 + 季节韵律”偏冰湖/冰海，不是普通湖泊泥岩。

## E. 湖泊相

### 环境与水动力

湖泊是大陆低洼、流水汇聚且与开阔海洋无直接连接的水体；构造和气候是主要控制因素。水动力包括湖浪、岸流、河流和重力流，潮汐弱。湖泊波浪基面一般<20m。湖水温度分层、季节混合，盐度变化大（淡水、微咸、咸水、盐湖）；淡水湖常有腹足类、双壳类、介形虫、鱼类和植物化石。

### 亚相与沉积

1. **湖成三角洲**：河流入湖减速，三角形/舌状、砂体厚大远伸；平原-前缘-前三角洲，顶积-前积-底积，整体下细上粗。
2. **扩张湖/洪水漫湖**：枯水面与洪水面之间，红色砂砾岩和杂色泥岩互层，交错层理、泥裂。
3. **滨湖**：浅水、氧化、湖浪和岸流强，泥滩、砂滩、砾滩；成熟砂岩，交错/水平层理。
4. **浅湖**：浪基面以上，粉砂和黏土，波状/水平层理，淡水化石，滩坝发育。
5. **滩坝**：成熟度高、少泥、波浪改造；楔形交错层理和透镜层理，常在三角洲侧缘或古隆起。
6. **湖湾**：砂嘴/砂坝障壁形成半封闭、低能、暗色粉砂质泥页岩，可含白云岩或油页岩；障壁推进形成下细上粗进积。
7. **半深湖**：浪基面以下、氧化界面以上，弱还原-还原；泥岩为主，水平层理，浮游生物、自生菱铁矿/黄铁矿。
8. **深湖**：最深、安静、还原；深色有机质泥岩/页岩、油页岩和泥灰岩，细水平纹层、黄铁矿，底栖生物缺失。
9. **湖泊重力流**：洪水型或滑塌型，可形成湖底扇、沟道和浊积砂体，常正粒序。

湖泊充填常由深湖/半深湖向上过渡为滨浅湖、三角洲和河流，形成下细上粗反旋回；构造沉降扩张期深湖和重力流发育，抬升收缩期三角洲、滩坝发育。

### 识别古代湖泊

- 岩性以泥岩、粉砂岩、砂岩为主，砾岩少；水平层理最常见，常有波痕、泥裂、雨痕。
- 淡水/广盐性介形虫、双壳、腹足、藻类和陆生植物丰富，缺海相生物。
- 环带状相带，范围比河流大而比海相小；深湖暗色、有机质高、黄铁矿多。
- 深湖生油，三角洲/浊积扇/滩坝提供储集砂体，泥岩提供盖层，常形成生储盖组合。

> [!warning] 易混点
> 湖泊和海相都可有水平层理、风暴沉积和重力流；区分要依靠生物组合、盐度指标、海绿石/海相化石、自生矿物和盆地边界，而不能只凭颜色或单个层理。
