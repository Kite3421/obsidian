# 固定学习流程

> [!important] 执行约定
> 每个新章节都遵循“完整主笔记 -> 学习中答疑（明确要求时再增补）-> 掌握检测 -> 收束复习笔记”四步。主笔记从一开始就能用于复习，不使用只有目录的占位式预习笔记。

## 学习偏好卡

- 学科：2026 考研数学二。
- 目标：120 分。
- 笔记平台：Obsidian 数学库。
- 资料策略：高数先复用 [[资料/高数两本讲义阅读索引|高数讲义索引]]，线代先复用 [[资料/线性代数讲义阅读索引|线代讲义索引]] 和已有文本缓存，再补读未覆盖章节。
- 教学节奏：先理解思路和方法识别，再进行计算训练；学习中允许随时提问。
- 笔记标准：开始时即生成可脱离聊天记录复习的完整主笔记。后续答疑默认不改笔记；只有你明确说“补入笔记”“记录到笔记”或等价指令时，才把该题、错因和修正补入同一页。
- 880 策略：按 [[资料/880处理流程|880 处理流程]] 执行；先由两本讲义界定范围，再逐题完成、验算、分层训练和变式回验。资料处理完成不等于你已掌握。

## 第一步：生成章节主笔记

开始新章节前：

1. 读取讲义中对应章节，以及已有的资料索引和学习记录。
2. 用讲义内容与必要的基础解释，生成一份可直接复习的完整章节主笔记，而非目录或占位式预习稿。
3. 主笔记应包含：章节目标、体系位置、前置知识、核心直觉、定义和公式条件、推导或理由、方法选择线索、完整代表题、易错点、应用、诊断、自检和资料来源。
4. 笔记内容完整不等于已经掌握；状态保持 `预习`、`待学习` 或 `学习中`，直到有检测证据。
5. 数学排版使用 `$...$` 表示行内公式、`$$...$$` 表示独立公式；不使用反斜杠圆括号或反斜杠方括号分隔符。

## 第二步：学习中答疑

学习过程中：

1. 你可以随时问概念、公式、例题、推导或做题卡点。
2. 我先定位卡点，再给当前最小必要的解释、提示或例子，不一次性把后续内容全部讲完。
3. 默认只在聊天中答疑，不写入主笔记或学习记录。只有你明确要求“补入笔记”“记录到笔记”或等价指令时，才在同一份章节主笔记的“学习中补充”写清问题、原因、最小例题和防坑结论，并按需更新学习记录。
4. 你没有明确表示掌握前，不提前把章节状态改为“已掌握”。

## 第三步：掌握检测

当你说“我学懂了”或主动要求检测时：

1. 根据讲义重点、你在学习中问过的问题和你的实际错误，生成针对性问题。
2. 检测覆盖四类证据：概念解释、方法选择、独立计算、变式或易错点判断。
3. 不以一道题答对作为掌握依据；需要确认你能说明“为什么这样选方法”。
4. 若存在卡点，先精确补该卡点，再用一道近似变式复检；通过后才进入收尾。

## 第四步：升级为复习笔记

确认掌握后：

1. 在原章节主笔记上校正和收束，不另建一份脱节的笔记。
2. 加入学习中真正问过的问题、你的典型错因、正确的判断线索、代表题思路和防坑提醒。
3. 删除只服务于当时听课的冗余内容，保留日后复习能快速恢复方法的内容。
4. 更新专题的状态、掌握度和下次复习时间；必要时创建错题记录。

## 复习笔记最低标准

- 能回答“这一章在解决什么问题”。
- 能从题目结构判断优先方法，而不是只背公式。
- 有你个人的错误路径和防坑提醒。
- 有少量能覆盖核心方法的代表题，而不是题海。
- 复习时可以用最后的自检题确认是否还会。
